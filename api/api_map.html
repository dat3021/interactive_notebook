🌐 API (Application Programming Interface)

Cầu nối trung tâm giao tiếp giữa Frontend, Backend, Mobile Apps, Microservices & 3rd Parties

• Client - Server Model & Request/Response

Client gửi yêu cầu (Request payload + headers) ➔ Server xử lý ➔ Trả về phản hồi (Status Code + response data).

• Endpoint & URI Structure

Địa chỉ URL định danh tài nguyên (VD: https://api.domain.com/v1/users/123).

• Statelessness (Tính Không Trạng Thái)

Mỗi request độc lập hoàn toàn, chứa đầy đủ thông tin xác thực mà không phụ thuộc vào bộ nhớ session server.

• Idempotency (Tính Lặp Lại An Toàn)

Hành động gọi API 1 lần hay $N$ lần cho ra cùng 1 kết quả (GET, PUT, DELETE có Idempotent; POST thì không).

• REST (Representational State Transfer) Resource-Based

Dựa trên URI định danh Resource + HTTP Verbs (GET/POST/PUT/DELETE). Dễ dùng, cache tốt, phổ biến nhất.

• GraphQL Query-Based

Client tự định nghĩa trường dữ liệu cần qua 1 endpoint duy nhất. Giải quyết triệt để Over-fetching/Under-fetching.

• gRPC (Google Remote Procedure Call) Action-Based

HTTP/2 + Protobuf nhị phân. Tốc độ siêu nhanh, latency cực thấp, chuẩn mực cho Microservices nội bộ.

• Event-Driven Architecture (EDA) & Webhooks Asynchronous

Giao tiếp bất đồng bộ qua Message Queues (Kafka/RabbitMQ) hoặc Webhooks tự động đẩy dữ liệu khi có sự kiện.

• WebSockets & Server-Sent Events (SSE) Real-Time

Duy trì kết nối 2 chiều liên tục (Full-duplex) cho Chat, Chứng khoán, Live Notification.

• SOAP (Simple Object Access Protocol) Enterprise XML

Giao thức nghiêm ngặt dựa trên XML + WSDL. Thường gặp trong hệ thống Ngân hàng, Tài chính cổ điển.

• HTTP/1.1 vs HTTP/2 vs HTTP/3 (QUIC)

HTTP/1.1 (Text-based, Head-of-line blocking) ➔ HTTP/2 (Multiplexing, Header Compression) ➔ HTTP/3 (UDP-based QUIC).

• TLS / HTTPS Encryption

Mã hóa toàn bộ dữ liệu trên đường truyền bằng SSL/TLS handshake chống nghe lén (Man-in-the-middle).

• HTTP Methods & Status Codes

Methods: GET, POST, PUT, PATCH, DELETE, OPTIONS. Codes: 2xx (Success), 3xx (Redirect), 4xx (Client Error), 5xx (Server Fault).

• JSON (JavaScript Object Notation)

Định dạng văn bản chuẩn quốc dân (application/json), nhẹ, human-readable.

• Protocol Buffers (Protobuf)

Định dạng nhị phân (Binary) siêu nhỏ nhẹ dùng trong gRPC, parse nhanh gấp nhiều lần JSON.

• Multipart/Form-Data

Định dạng chuyên dụng để Upload tập tin, hình ảnh, tài liệu lên Server.

• Authentication (AuthN) vs Authorization (AuthZ)

AuthN: Xác định bạn là ai (Login). AuthZ: Xác định bạn có quyền làm gì (Role / Permission).

• API Key, JWT (JSON Web Token) & OAuth 2.0 / OIDC

API Key cho 3rd Party service, JWT cho Stateless Session, OAuth2 cho đăng nhập tập trung (Google/FB).

• Rate Limiting, CORS & OWASP API Top 10

Chống Spam/DDoS bằng Rate Limit; cấu hình CORS chặn Web lạ; phòng thủ BOLA/BFLA theo chuẩn OWASP.

• API-First / Design-First Approach

Viết tài liệu Specification (OpenAPI/Swagger) trước khi bắt đầu gõ code backend.

• API Versioning Strategy

Đánh phiên bản qua URL Path (/v1/), Query Parameter hoặc Header để tránh làm gãy App cũ.

• Pagination Patterns (Offset vs Cursor-based)

Phân trang danh sách lớn bằng Offset/Limit đơn giản hoặc Cursor-based tối ưu hiệu năng CSDL lớn.

• Standardized Error Format (RFC 7807)

Chuẩn hóa cấu trúc JSON thông báo lỗi chứa type, title, status, detail, instance.

• API Gateway (Kong, Nginx)

Cổng giao tiếp tập trung xử lý Routing, Authentication, SSL Termination & Caching.

• Caching Layer (Redis)

Lưu đệm kết quả truy vấn phổ biến trong bộ nhớ RAM để phản hồi dưới 5ms.

• Observability & Testing

Monitoring (Prometheus/Grafana), Distributed Tracing (Jaeger) & Contract Testing (Pact).
